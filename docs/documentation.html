Documentation & Data Schema
Field definitions, data sources, pipeline versions, and usage notes for the Corpusome v1.1 release.
Current release: v1.1 — expanded from v1.0 (30,680 samples) by pulling the full EBI MGnify human body-site catalogue (708 studies, 156,866 samples). Pipeline: MetaPhlAn3 + HUMAnN3 (shotgun); Greengenes 13_8 / SILVA SSU (16S).
Corpus Metadata Schema

Primary file: data/metadata/corpus_metadata_catalog_expanded.{parquet,csv} — 187,546 rows × 15 columns.

Field Type Description Example
sample_uid string Unique sample identifier. Format: study:sample_id for cMD; raw run accession for MGnify. AsnicarF_2017:MV_FEI1_t1Q14
source string Contributing database. MGnify_full = full EBI catalogue pull; curatedMetagenomicData = cMD v3.18; AGP = American Gut Project; MGnify = earlier selective MGnify pull. curatedMetagenomicData
study string Study or project identifier. For cMD: author+year (e.g. AsnicarF_2017); for MGnify: EBI project accession (e.g. MGYS00001234); for AGP: Qiita_10317. MGYS00002925
modality string Sequencing modality. 16S = amplicon 16S rRNA; shotgun = whole-genome shotgun. Do not merge these tiers — different profilers, incompatible feature spaces. 16S
body_site string Harmonized anatomical body site. Values: stool, oral, skin, respiratory, urogenital, milk. Mapped from free-text EBI body-site annotations. stool
region string 16S hypervariable region amplified. Empty for shotgun samples. Relevant for downstream analysis (e.g. V4 for AGP, various for MGnify). V4
pipeline string Bioinformatics pipeline string (verbatim from source). cMD: MetaPhlAn3 + HUMAnN (cMD 3.18 / 2021-10-14 snapshot); AGP: Greengenes 13_8 closed-ref (deblur precomputed round 1-21). MetaPhlAn3 + HUMAnN …
host_age float Host age in years at sampling. May be NaN when not provided. Range: 0–101 years in AGP; most cMD studies have age. 32.0
host_sex string Biological sex. Values: male, female, or blank. For AGP: derived from questionnaire; for cMD: from original study metadata. female
subject_id string De-identified subject identifier. Long hashed IDs in AGP; short human-readable codes in cMD. Use for longitudinal linking within a study. MV_FEI1
country string ISO 3166-1 alpha-3 country code of sample collection. Populated only for cMD shotgun tier (42 countries). Empty for MGnify and AGP in this release. USA
sequencing_platform string Sequencing instrument. Examples: IlluminaHiSeq, IlluminaNovaSeq, IlluminaMiSeq, IonProton. Relevant as a batch effect co-variate. IlluminaHiSeq
disease string Disease/diagnosis label from original study (shotgun tier only). 141 distinct conditions. healthy for controls. IBD
study_condition string Study arm label, e.g. control, case, treatment. More granular than health_status. control
health_status string Curated health status. Values: healthy (14,566), diseased (8,022), unlabeled (164,958 — entire 16S tier). Use with caution for pretraining; do not filter out unlabeled samples. healthy

Processing Pipeline (v1.1)

Executed via pipeline/run.sh. Numbered scripts in pipeline/.

1

Data Acquisition

curatedMetagenomicData v3.18 (2023 snapshot) via R package; American Gut Project (Qiita study 10317) via Qiita public API; EBI MGnify full human body-site catalogue via SSU taxonomy tables API (mgnify_full_download_manifest.csv records per-study provenance).

2

16S Harmonization

Terminal genus tokens extracted from Greengenes 13_8 (AGP) and SILVA SSU r138 (MGnify) lineage strings. Tokens prefixed g__; genus-level columns retained only if present in ≥10 samples corpus-wide. Final vocabulary: 977 genus tokens.

3

Shotgun Profiling (cMD tier)

MetaPhlAn3 (mpa_vJan21_CHOCOPhlAnSGB_202103) species-level relative abundances; HUMAnN3 (v3.0) pathway abundances (MetaCyc). Source: curatedMetagenomicData 3.18 / 2021-10-14 snapshot. Not reprocessed from raw reads in this release.

4

Metadata Harmonization

Body-site labels mapped to controlled vocabulary (stool / oral / skin / respiratory / urogenital / milk) from free-text EBI environment biome annotations. Health status unified across disease and study_condition fields to health_status ∈ {healthy, diseased, unlabeled}.

5

Quality Checks

Duplicate sample_uid check (0 duplicates); relative abundance sum check (all rows sum to ≤1.0 ± 1×10⁻⁶); minimum read count filter (samples with <10k reads excluded upstream by EBI/cMD). See documents/validation_summary.json.
